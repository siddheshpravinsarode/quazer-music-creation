1. The Scale Gatekeeper (The Matrix of Legal Notes)

The simplest rule you can give a logic engine is a look-up array of valid frequencies, usually based on a specific musical scale.

In music theory, certain notes sound naturally pleasing together (consonant), while others clash heavily (dissonant).

    The Rule: You hardcode an array of notes, like the Minor Pentatonic Scale (famous for blues, rock, and sci-fi synth music).

    The Logic: When the computer wants to pick a note, it can choose randomly, but it is strictly forbidden from picking any frequency outside that specific array. Because everything inside that array blends beautifully, the computer can play blind folded and it will never hit a wrong note.

2. Markov Chains (State-Based Probability Matrices)

If you want the computer to compose melodies that feel like they have a structural flow—where one note logically leads to the next—you use a Markov Chain.

A Markov Chain is a state machine where the next choice depends entirely on the current choice, driven by a table of probabilities. You train or program the engine with specific rules:

    If the current note is C, there is a 60% chance the next note should be G (sounds stable), a 30% chance it jumps to E, and only a 10% chance it jumps to a high B.

    If the engine rolls a random number and lands on G, the probability matrix instantly shifts to a new set of rules specifically for what follows a G.

             [ 60% ] ───> Note G ───> (Shifts to G's Rule Table)
            /
   Current Note: C ─────> [ 30% ] ───> Note E
            \
             [ 10% ] ───> Note B

By tweaking these probability percentages in your code, you can give your AI composer a specific personality. High jump probabilities make the music frantic and chaotic; low jump probabilities make it smooth and ambient.
3. L-Systems and Fractals (Algorithmic Math Trees)

If you want to generate infinite, complex symphonies that never repeat themselves but still have an overarching structural theme (like a classical sonata), you use L-Systems (Lindenmayer Systems) or fractal math.

L-Systems use string-rewriting rules to generate massive, branching structures. They are the exact same math rules video game engines use to procedurally grow realistic trees and plants.
How that translates to music:

    You define a starter string: A

    You define transformation rules:

        A -> B + A

        B -> C - B

    The logic engine runs a loop to expand the string recursively:

        Generation 1: A

        Generation 2: B + A

        Generation 3: C - B + B + A

    The engine reads the final long string map: C means play a low note, - means drop the tempo, B means play a chord, and + means speed up the rhythm.

The code maps these geometric mathematical branches directly onto musical arrangements. The result is a soundtrack that has sweeping, structural movements that mirror the patterns found in natural structures like snowflakes or coastlines.
